# ADR-0001: Плагин изоляциясы — әр плагинге жеке ClassLoader

Мәртебесі: қабылданды
Күні: 2026-11-18 · Қатысушылар: Амангелді Мадияр

## Контекст

R2: плагин хосттың ішкі кластарын емес, тек хост API-ін көруі керек. R6: плагинді хостты қайта іске қоспай жаңарту керек, ал ескі нұсқаның кластары жадтан шығуы тиіс. Java-да класты тек оны жүктеген ClassLoader-мен бірге ғана шығаруға (unload) болады.

## Нұсқалар

1. **Барлық плагинге бір ортақ ClassLoader (немесе хост classpath-ы).**
   + Қарапайым.
   − Изоляция жоқ: плагин `kz.madiyar.plugins.host.*`-ты еркін қолданады.
   − Кластарды шығаруға болмайды → hot reload мүмкін емес (R6 орындалмайды).
2. **Әр плагинге жеке `URLClassLoader`, ата-анасы — application loader.**
   + Hot reload мүмкін.
   − Parent-first делегация салдарынан плагин хост classpath-ындағы бәрін көреді → R2 бұзылады.
3. **Әр плагинге жеке `PluginClassLoader`: ата-анасы — platform loader, API пакеті хосттан делегирленеді (таңдалды).**
   + Плагин тек `java.*`, `kz.madiyar.plugins.api.*` және өз JAR-ын көреді.
   + `host.*` пакеті үшін `ClassNotFoundException` түсінікті хабарламамен.
   + API класы хостпен **ортақ** (`Plugin.class` бір объект) → хост плагинді `Plugin` ретінде қолдана алады.
   + Loader-ді тастасақ, GC оның кластарын шығарады → R6.
   − Плагиндер бір-бірінің кластарын көрмейді (тәуелділік тек жүктеу ретіне әсер етеді).
4. **JPMS `ModuleLayer`.**
   + Стандартты, күшті инкапсуляция.
   − Плагин JAR-лары `module-info` талап етеді, күрделілігі жоғары, 1,5 апта мерзімге артық.

## Шешім

3-нұсқа. Ережені екі қабатпен қорғаймыз:
- **компиляция деңгейінде** — ArchUnit (`ArchitectureTest.samplePluginsDependOnlyOnApi`), ал ереженің «әлсіз» емес екенін `ruleCatchesPluginThatUsesHostInternals` дәлелдейді;
- **орындалу кезінде** — `PluginClassLoader` (`PluginClassLoaderTest.pluginThatUsesHostInternalsFailsAtRuntime`), себебі бөгде плагин дайын JAR ретінде келуі мүмкін.

## Салдары

+ R2 және R6 бір шешіммен орындалады.
− Плагиндер арасында класс бөлісу жоқ; керек болса, келешекте «экспортталатын пакеттер» механизмін қосу керек (ашық сұрақ, README).
